# Real Estate AI Guide

An interactive guide for real estate agents to learn and implement AI automation in their business.

## Overview

This guide teaches agents the complete journey:
- **Phase 1-4**: Learn the framework and build your first AI prompt
- **Phase 5**: Save your prompt in your AI tool
- **Phase 6**: Connect tools with connectors for full automation

## Features

- Interactive expandable sections for 4 real estate functions
- Copy-to-clipboard example prompts
- Fillable workflow mapping and prompt templates
- Download all prompts and templates as markdown
- Hello Brain design branding
- Mobile responsive

## Real Estate Functions Covered

1. Marketing & Listing Promotion
2. Lead Management & Nurturing
3. Client Communication
4. Prospecting & Lead Generation

## Deployment

Deployed to Vercel at: https://real-estate-ai-guide.vercel.app

Subdomain: gethellobrain.com/real-estate

## Technical

- Pure HTML/CSS/JavaScript (no build required)
- Vanilla JavaScript with localStorage for template autosave
- Hello Brain brand colors and typography
- Self-contained single-page application
